# PennyQuest for Android

PennyQuest is a gamified personal finance app: track spending, budgets, and savings goals, import bank, credit card, and Robinhood statements, and earn points and streaks for keeping up. Everything stays on your phone.

## Download

**[Download the latest APK](https://github.com/IcyHunter22/PennyQuest-download/releases/latest/download/PennyQuest.apk)**

Or see all versions on the [Releases page](https://github.com/IcyHunter22/PennyQuest-download/releases).

## Install

1. Open the download link on your Android phone (Android 8.0 or newer).
2. Open the downloaded `PennyQuest.apk`.
3. If Android asks, allow your browser to **install unknown apps**, then tap **Install**.

Updates install over the previous version and keep your data.

This repository only hosts the app for download; the source code is private.
